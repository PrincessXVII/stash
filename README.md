# Stash

клиентский мод под fabric 1.21.11. запоминает, что лежало в сундуках, бочках, шалкерах и прочих хранилищах, которые ты открывал, и ищет предмет по этому списку.

база хранится у тебя: `config/stash/stash.sqlite`. на сервер ничего не уходит.

открывается на `H` или через `/stash`. клик по строке копирует координаты, shift-клик забывает место.

видно только то, что сервер показал, когда ты открывал хранилище. закрытый сундук на другом конце базы сам собой в списке не появится.

нужна java 21.

```
./gradlew build
```

jar появится в `build/libs/stash-1.0.0.jar`, кидаешь в `mods` рядом с fabric api.

```
./gradlew test
```
